# Apex Auto Hub

Car Dealership Website Requirements

1. Website Objective

Create a modern, premium and trustworthy car dealership website that showcases our available vehicles and makes it easy for customers to browse, enquire about and purchase vehicles.

The website should feel professional, automotive-focused, modern and slightly sporty, while remaining simple and easy to navigate.

The website must work perfectly across:

Desktop

Tablet

Mobile

The overall design should use the company’s brand colours:

Black — primary/dominant colour

Silver / Grey — secondary colour

Red — accent colour used for buttons, highlights and important interactive elements

White/light grey may be used where necessary for readability and contrast.

2. Website Style & Branding

The design should have a premium automotive feel rather than looking like a generic car dealership template.

Visual direction

Think:

Modern

Premium

Clean

Automotive

Slightly aggressive/sporty

High-quality imagery

Smooth animations

Strong typography

Dark theme

Avoid:

Overly colourful designs

Cluttered pages

Excessive animations

Cheap/template-like appearance

Too much red

Red should primarily be used as an accent colour to draw attention to important actions.

3. Navigation

The website should have a clear navigation bar.

Main navigation

Home

Cars / Stock

About Us

Import / Services

Finance

Contact

There should also be a prominent “View Cars” or “Browse Stock” button.

The navigation should remain easily accessible on mobile through a hamburger menu.

4. Homepage

The homepage should immediately communicate who we are and showcase our vehicles.

Hero Section

The hero should be one of the most visually impressive parts of the website.

Instead of a basic static banner, create a fun interactive automotive hero.

Suggested concept

A large hero section featuring a premium vehicle with interactive movement.

Possible interactions:

Vehicle subtly moves/rotates as the user moves their mouse/finger

Parallax movement between the car, background and foreground

Interactive headlights or light effects

Subtle red accent animations

Scroll interaction that transitions from the hero into the vehicle inventory

Hovering/clicking elements could reveal vehicle information

The interaction should feel smooth and premium, not like a gimmick.

Hero content

Example:

YOUR NEXT CAR STARTS HERE.

Premium imported vehicles.
Quality cars. Straightforward service.

[ VIEW OUR CARS ]

[ GET IN TOUCH ]

The hero should prominently feature a vehicle from our current stock where appropriate.

Immediately below the hero, display a selection of our current vehicles.

For example:

Featured Stock

Each card should include:

It should contain all currently available vehicles.

Vehicle filtering

[Filters] [Sort By]

Every vehicle should have its own dedicated page.

This page should provide comprehensive information about the vehicle.

Vehicle gallery

Large, high-quality photographs should be displayed.

The gallery should support:

Multiple photos

Thumbnail navigation

Optional video

8. Enquiry / Contact From Vehicle Page

Every vehicle page should have a prominent enquiry section.

Example:

Interested in this vehicle?

[ ENQUIRE NOW ]

The customer should be able to submit:

Name

Phone number

Email

Message

The selected vehicle should automatically be included in the enquiry so we know which car the customer is asking about.

Example:

I’m interested in the 2019 Toyota Aqua.

There should also be buttons for:

Call

WhatsApp

Email

9. About Us Page

Create a dedicated page explaining the dealership.

Content

The page should explain:

Who we are

What the dealership does

What makes us different

Our approach to sourcing vehicles

Our commitment to quality

Our customer service

The page should use professional dealership photography where available.

It should feel personal and trustworthy rather than corporate.

10. Import / Vehicle Sourcing Page

Because the dealership specialises in imported vehicles, create a dedicated section/page explaining the import process.

Suggested sections

How We Source Our Cars

Explain how vehicles are sourced and selected.

Vehicle Selection

Explain how vehicles are inspected/selected before being purchased.

Import Process

Explain the process from sourcing the vehicle to its arrival in Ireland.

Preparation

Explain any preparation, checks and servicing carried out before the vehicle is offered for sale.

Ready for You

Explain how the vehicle is prepared for the customer.

A visual timeline would work well here:

Japan → Inspection → Purchase → Shipping → Ireland → Preparation → Customer

This section could also use subtle animations.

11. Finance Page

Create a finance information page explaining available finance options.

The page should include:

Finance options

Example monthly repayments

Deposit information

Application process

Finance enquiry form

If a third-party finance provider is used, the website should clearly identify this.

Include a strong CTA:

Find out how affordable your next car could be.

[ APPLY / ENQUIRE ABOUT FINANCE ]

Make

Colour

Features

Remove / hide vehicles

Vehicles that are sold should be able to be:

Removed from active stock

Archived

Micro-animations

Animations should be fast and smooth and should not negatively affect website performance.

17. Mobile Experience

Mobile should be treated as a priority.

The website must be fully responsive.

On mobile:

Vehicle images should remain large and high quality

Filters should be easy to use

Buttons should be easy to tap

WhatsApp/call buttons should be easily accessible

Image galleries should support swiping

Navigation should use a mobile menu

Forms should be simple to complete

The website should feel like a premium mobile experience, not simply a desktop website squeezed onto a phone.

18. Calls to Action

The website should consistently guide customers towards taking action.

Important CTAs:

View Cars

Browse Stock

Enquire Now

Call Us

WhatsApp Us

Get Finance

Contact Us

Red should be used strategically for these buttons.

19. SEO

The website should be built with SEO in mind.

Each vehicle should have its own searchable page.

Include:

SEO-friendly URLs

Fast page loading

20. Performance

The website should load quickly despite using high-quality vehicle photography.

Requirements:

Optimised images

Lazy loading

Responsive images

Efficient animations

Minimal unnecessary scripts

Good Core Web Vitals

Fast mobile loading

The interactive hero should not significantly slow down the website.

21. Trust & Credibility

The website should make customers feel comfortable buying from the dealership.

Potential sections:

Customer reviews

Google reviews

Vehicles sold

Years of experience

Import expertise

Warranty information

Finance information

Frequently asked questions

If genuine customer testimonials are available, display them prominently.

23. Overall User Journey

The ideal customer journey should be:

Homepage

↓

See interactive hero

↓

Browse Featured Cars

↓

Open Vehicle

↓

View photos + specifications + description

↓

Enquire / WhatsApp / Call

↓

Arrange viewing / purchase

The website should make this journey as frictionless as possible.

24. Key Design Principle

The website should ultimately feel like a modern automotive brand, not simply an online catalogue of cars.

The cars should be the stars of the website.

The design, animations, typography and interactions should support the vehicles rather than distract from them.

The overall impression we want customers to have is:

Premium. Trustworthy. Modern. Automotive. Professional.

Brand identity should consistently use black, silver/grey and red throughout the website.
